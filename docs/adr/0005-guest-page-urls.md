# Адреса страниц гостя: `/`, `/book`, `/book/:slug`

Страницы гостя живут по адресам `/` (главная), `/book` (страница записи со списком типов встреч) и `/book/:slug` (страница типа встречи). Мы отклоняемся от Cal.com и от сценария README с `/<владелец>/consultation`: владелец один (ADR-0003), поэтому сегмент владельца ничего не различает. Общий префикс `/book` не даёт slug'у типа встречи совпасть с адресами разделов владельца.

## Considered Options

- **`/<имя-владельца>/:slug`, как у Cal.com** — отвергнут: имя единственного владельца пришлось бы хранить в настройках только ради адреса.
- **`/:slug` от корня** — отвергнут: slug вроде `event-types` занял бы адрес будущего раздела владельца.

## Consequences

- Если владельцев станет несколько, адреса придётся менять (например, на `/book/<владелец>/:slug`), а старые ссылки перестанут работать.
