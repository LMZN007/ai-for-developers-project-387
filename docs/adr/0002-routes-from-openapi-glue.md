# Маршруты бекенда строятся из OpenAPI через fastify-openapi-glue

Fastify не объявляет маршруты вручную: `fastify-openapi-glue` читает сгенерированный `openapi.yaml`, создаёт маршруты и валидацию запросов и ответов, а обработчики ищет в `apps/api/src/handlers.ts` по `operationId` (например, `Health_check`). Так невозможно реализовать маршрут, которого нет в контракте (ADR-0001), а валидация не дублируется в коде.

## Consequences

- Имя метода в `handlers.ts` обязано совпадать с `operationId`; переименование операции в TypeSpec ломает обработчик.
- Отказ от библиотеки потребует переписать регистрацию всех маршрутов и валидацию вручную.
