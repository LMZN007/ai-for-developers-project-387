# Маршрутизация фронтенда — React Router в library mode

Фронтенд (Vite + React) переключает страницы на клиенте через React Router (v8) в library mode: маршруты объявляются компонентами, без файлового роутинга и без framework mode (там React Router сам становится сборщиком и сервером). Страниц немного, и широко известная библиотека с большой документацией здесь полезнее строгой типизации.

## Considered Options

- **TanStack Router** — отвергнут: типизирует параметры URL, но требует плагина Vite и генерации дерева маршрутов, а при 2–3 страницах это лишняя настройка.
- **wouter** — отвергнут: слишком минимальный, вложенные макеты и загрузку данных пришлось бы делать самим.
- **React Router framework mode** — отвергнут: заменяет связку Vite + SPA на свой сборщик и SSR, которые проекту не нужны.
