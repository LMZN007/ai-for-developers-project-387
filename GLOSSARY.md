# Календарь звонков

Сервис записи на встречи по образцу Cal.com: владелец публикует типы встреч и свою доступность, гость выбирает свободный слот и записывается.

## Роли

**Владелец**:
Человек, который создаёт типы встреч, задаёт доступность и принимает записи.
_Avoid_: хост, организатор, админ, пользователь

**Гость**:
Человек, который записывается на встречу к владельцу по публичной ссылке.
_Avoid_: клиент, посетитель, участник, пользователь

## Расписание

**Тип встречи**:
Шаблон встречи владельца: название, ссылка (slug), необязательное описание и длительность в минутах.
_Avoid_: событие, услуга, мероприятие, event

**Доступность**:
Рабочие часы владельца по дням недели вместе с его часовым поясом.
_Avoid_: расписание, график, рабочее время

**Слот**:
Свободный отрезок времени длиной в тип встречи, который целиком лежит внутри доступности и не занят записью.
_Avoid_: окно, таймслот, интервал

**Горизонт записи**:
Период, на который гость может записаться вперёд: 14 календарных дней начиная с сегодняшнего, считая дни по часовому поясу владельца.
_Avoid_: окно записи, окно бронирования, период

**Запись**:
Занятый гостем слот конкретного типа встречи вместе с данными гостя (имя, email, комментарий).
_Avoid_: бронирование, бронь, booking, встреча (как синоним записи)

**Предстоящая запись**:
Запись, которая ещё не закончилась; только такие владелец видит в разделе «Записи».
_Avoid_: будущая запись, активная запись

**Конфликт**:
Попытка записаться на время, которое пересекается с уже существующей записью любого типа встречи; конец записи в её время не входит, поэтому запись, начинающаяся ровно в конце другой, конфликтом не является.
_Avoid_: коллизия, накладка, двойная бронь

## Страницы гостя

**Главная**:
Страница о сервисе, которая ведёт гостя к странице записи.
_Avoid_: лендинг, стартовая

**Страница записи**:
Страница со списком типов встреч владельца, открытая гостю; с неё гость начинает запись.
_Avoid_: страница бронирования, профиль, страница владельца

**Страница типа встречи**:
Страница одного типа встречи по адресу `/book/:slug`, где гость выбирает день и слот (шаг 3 сценария в README).
_Avoid_: публичная страница, страница события
